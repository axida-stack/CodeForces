# G2. Lakeside Trail (Hard Version)

time limit per test: 4 seconds

memory limit per test: 256 megabytes

This is the hard version of the problem. The two versions differ only in the constraints on 𝑛
, on the sum of 𝑛
 over all test cases, and on the number of test cases.

A circular trail around a lake consists of 𝑛
 sections numbered from 1
 to 𝑛
 along the trail. The height of the 𝑖
-th section is ℎ𝑖
. Sections 𝑖
 and 𝑖+1
 are adjacent for each 𝑖
 from 1
 to 𝑛−1
, and sections 𝑛
 and 1
 are adjacent as well.

The steepness of the trail is the maximum absolute difference between the heights of two adjacent sections. In other words, the steepness is max1≤𝑖≤𝑛|ℎ𝑖−ℎ𝑖+1|
, where ℎ𝑛+1
 should be considered to exist and to be equal to ℎ1
.

You have 𝑘
 units of soil. One unit of soil increases the height of one section by 1
; several units may be used on the same section. Soil cannot be removed, so the heights can only increase.

Find the minimum possible steepness of the trail after using at most 𝑘
 units of soil.

- Input

Each test contains multiple test cases. The first line contains the number of test cases 𝑡
 (1≤𝑡≤10^4
). The description of the test cases follows.

The first line of each test case contains two integers 𝑛
 and 𝑘
 (3≤𝑛≤10^6
, 0≤𝑘≤10^18
) — the number of sections and the number of units of soil.

The second line contains 𝑛
 integers ℎ1,ℎ2,…,ℎ𝑛
 (1≤ℎ𝑖≤109
) — the heights of the sections.

It is guaranteed that the sum of 𝑛
 over all test cases does not exceed 10^6
.

- Output

For each test case, print a single integer — the minimum possible steepness of the trail after using at most 𝑘
 units of soil.

Example


- input
  ```
  6
  4 3
  1 5 2 8
  5 5
  2 9 4 1 6
  3 0
  1 4 7
  3 100
  1 10 1
  5 5
  4 1 1 1 1
  6 14
  3 6 2 4 1 5
  ```
- output
  ```
  5
  4
  6
  0
  2
  1
  ```

- Note

In the first test case, you can use two units of soil on section 1
 and one unit on section 3
. The heights become 3,5,3,8
, and the differences between adjacent sections are 2
, 2
, 5
, and 5
, the last one being between sections 4
 and 1
. So the steepness is 5
.

In the fourth test case, all heights can be made equal to 10
 using 18
 units of soil.

In the fifth test case, the heights can become 4,2,1,1,2
 using 1+1=2

 and 5
 are adjacent to it, so they would have to be raised to at least 3

 and 4
 to at least 2
, which needs 2+1+1+2=6
 units of soil.


```C

#include <stdio.h>
#include <stdlib.h>

typedef long long ll;

int n;
ll k;

ll *a;          // 复制三份后的高度数组
ll *leftBest;   // 保存每个位置的左侧最大值
int *dq;        // 单调队列

// 判断最大相邻高度差 D 是否可行
int check(ll D) {
    int r = n / 2;
    int head, tail;
    int i, j;

    ll cost = 0;

    // ==================================
    // 第一遍：计算每个位置的左侧最大值
    // max(a[j] + D*j) - D*i
    // ==================================

    head = tail = 0;

    // 初始化第一个窗口 [n-r, n-1]
    for (j = n - r; j < n; j++) {
        ll val = a[j] + D * j;

        while (tail > head) {
            int last = dq[tail - 1];

            if (a[last] + D * last <= val)
                tail--;
            else
                break;
        }

        dq[tail++] = j;
    }

    // 处理中间一份数组
    for (i = n; i < 2 * n; i++) {
        ll val = a[i] + D * i;

        while (tail > head) {
            int last = dq[tail - 1];

            if (a[last] + D * last <= val)
                tail--;
            else
                break;
        }

        dq[tail++] = i;

        // 删除窗口左侧以外的元素
        while (dq[head] < i - r) {
            head++;
        }

        int pos = dq[head];

        leftBest[i - n] = a[pos] + D * pos - D * i;
    }

    // ==================================
    // 第二遍：计算每个位置的右侧最大值
    // max(a[j] - D*j) + D*i
    // ==================================

    head = tail = 0;

    // 初始化最后一个窗口 [2*n-1, 2*n-1+r]
    for (j = 2 * n - 1 + r; j >= 2 * n - 1; j--) {
        ll val = a[j] - D * j;

        while (tail > head) {
            int last = dq[tail - 1];

            if (a[last] - D * last <= val)
                tail--;
            else
                break;
        }

        dq[tail++] = j;
    }

    for (i = 2 * n - 1; i >= n; i--) {
        // 右侧最大值
        int pos = dq[head];

        ll rightBest = a[pos] - D * pos + D * i;

        // 左右两侧取最大值
        ll need = leftBest[i - n];

        if (rightBest > need) {
            need = rightBest;
        }

        // 计算需要增加的土壤
        cost += need - a[i];

        if (cost > k) {
            return 0;
        }

        // 移动到左边一个位置
        if (i > n) {
            int idx = i - 1;
            ll val = a[idx] - D * idx;

            while (tail > head) {
                int last = dq[tail - 1];

                if (a[last] - D * last <= val)
                    tail--;
                else
                    break;
            }

            dq[tail++] = idx;

            // 删除窗口右侧以外的元素
            while (dq[head] > idx + r) {
                head++;
            }
        }
    }

    return 1;
}

void solve() {
    scanf("%d %lld", &n, &k);

    a = (ll *)malloc(sizeof(ll) * 3 * n);
    leftBest = (ll *)malloc(sizeof(ll) * n);
    dq = (int *)malloc(sizeof(int) * 3 * n);

    // 读取原数组
    for (int i = 0; i < n; i++) {
        scanf("%lld", &a[i]);
    }

    // 复制三份
    for (int i = 0; i < n; i++) {
        a[i + n] = a[i];
        a[i + 2 * n] = a[i];
    }

    // 二分答案
    ll left = 0;
    ll right = 1000000000LL;

    while (left < right) {
        ll mid = left + (right - left) / 2;

        if (check(mid)) {
            right = mid;
        } else {
            left = mid + 1;
        }
    }

    printf("%lld\n", left);

    free(a);
    free(leftBest);
    free(dq);
}

int main() {
    int t;
    scanf("%d", &t);

    while (t--) {
        solve();
    }

    return 0;
}
```
