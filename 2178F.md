# 2178F - Conquer or of Forest

[Problem Link](https://codeforces.com/contest/2178/problem/F)

**Time Limit:** 2 seconds  
**Memory Limit:** 512 MB

## Problem Statement

A rooted tree has a unique coloring determined by the size of each vertex's subtree:

- A vertex is **White** if its subtree contains an even number of vertices.
- Otherwise, it is **Black**.

Yuuki is given a tree $T$ with $n$ vertices labeled from $1$ to $n$, rooted at vertex $1$, and colored according to the above rule.

A tree is considered **Conquered** if at least one of the following conditions is satisfied:

1. The tree contains no White vertices.
2. There exists a vertex $v$ such that every White vertex lies on the simple path from vertex $1$ to vertex $v$.

Yuuki can perform the following operation any number of times (possibly zero):

1. Choose a White vertex $w$ that is not the root. Let $p_w$ be its parent.
2. Remove the edge $(p_w,w)$.
3. Add an edge between any two vertices such that the resulting graph remains a tree.
4. Recolor all vertices according to the subtree-size coloring rule. The root remains vertex $1$.

Yuuki must complete the entire operation, including recoloring, before checking whether the tree is Conquered. He may also perform an operation on a tree that is already Conquered.

Two trees are considered different if their edge sets differ.

Determine the number of distinct Conquered trees that can be obtained from the initial tree by applying the operation any number of times.

Since the answer may be large, output it modulo $998244353$.

## Input

The first line contains an integer $t$ ($1\le t\le 10^4$), the number of test cases.

Each test case is described as follows:

- The first line contains an integer $n$ ($2\le n\le 2\cdot10^5$), the number of vertices.
- The following $n-1$ lines each contain two integers $u_i$ and $v_i$ ($1\le u_i<v_i\le n$), describing an edge between vertices $u_i$ and $v_i$.

The given edges form a tree.

The sum of $n$ over all test cases does not exceed $2\cdot10^5$.

## Output

For each test case, output one integer: the number of distinct Conquered trees obtainable from the initial tree, modulo $998244353$.

## Note

In the first test case, four distinct Conquered trees can be constructed.

- The original tree is already Conquered because all White vertices lie on the path from vertex $1$ to vertex $4$.
- By selecting vertex $3$, removing edge $(1,3)$, and connecting vertices $2$ and $4$, a Conquered tree can be obtained.
- By selecting vertex $3$, removing edge $(1,3)$, and connecting vertices $2$ and $3$, another Conquered tree can be obtained.
- By performing two operations, first selecting vertex $3$ and connecting vertices $2$ and $4$, then selecting vertex $4$ and connecting vertices $1$ and $4$, a fourth Conquered tree can be obtained.

In the second test case, the tree contains no White vertices. No operation can be performed, and the original tree is already Conquered. Therefore, the answer is $1$.


```C++
#include <iostream>
#include <vector>
using namespace std;

using ll = long long;

const ll MOD = 998244353;

ll qpow(ll a, ll b){
    ll res = 1;
    while (b){
        if (b & 1){
            res = res * a % MOD;
        }
        a = a * a % MOD;
        b >>= 1;
    }
    return res;
}
void solve(){
    int n;
    cin >> n;
    vector<vector<int>> g(n+1);
    for (int i=1; i<n; i++){
        int u, v;
        cin >> u >> v;
        g[u].push_back(v);
        g[v].push_back(u);
    }
    
    vector<int> parent(n+1, 0);
    vector<int> order;
    order.push_back(1);
    parent[1] = -1;
    
    for (int i=0; i<order.size(); i++){
        int u = order[i];
        for (int v : g[u]){
            if (v==parent[u]) continue;
            parent[v] = u;
            order.push_back(v);
        }
    }
    
    vector<int> sz(n+1, 1);
    for (int i=n-1; i>=0; i--){
        int u = order[i];
        if (parent[u]!=-1){
            sz[parent[u]] += sz[u];
        }
    }
    
    vector<bool> white(n+1, false);
    for (int u=1; u<=n; u++){
        white[u] = (sz[u]%2==0);
    }
    
    vector<int> cnt(n+1, 1);
    for (int i=n-1; i>=0; i--){
        int u = order[i];
        for (int v : g[u]){
            if (parent[v]==u && !white[v]){
                cnt[u] += cnt[v];
            }
        }
    }
    
    vector<int> blocks;
    for (int u=2; u<=n; u++){
        if (white[u]){
            blocks.push_back(cnt[u]);
        }
    }
    
    int k=(int)blocks.size();
    if (k==0){
        cout << 1 << endl;
        return;
    }
    
    ll ans = cnt[1];
    
    for (int i=1; i<=k-1; i++){
        ans = ans * i % MOD;
    }
    ll product = 1;
    ll sum = 0;
    for (int x : blocks){
        ll a = x;
        product = product * a % MOD * a % MOD;
        sum = (sum + qpow(a, MOD-2))%MOD;
    }
    ans = ans * product % MOD;
    ans = ans * sum % MOD;
    cout << ans << endl;
}

int main(){
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    
    int t;
    cin >> t;
    
    while (t--) {
        solve();
    }
    return 0;
}
```
