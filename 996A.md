# Hit the Lottery

time limit per test1 second

memory limit per test256 megabytes

Allen has a LOT of money. He has 𝑛 dollars in the bank. For security reasons, he wants to withdraw it in cash (we will not disclose the reasons here). The denominations for dollar bills are 1, 5, 10, 20, 100. 
 What is the minimum number of bills Allen could receive after withdrawing his entire balance?

- Input

The first and only line of input contains a single integer 𝑛 (1≤𝑛≤109).

- Output

Output the minimum number of bills that Allen could receive.

Examples:

- input
  ```
  125
  ```
- output
  ```
  3
  ```
- input
  ```
  43
  ```
- output
  ```
  5
  ```
- input
  ```
  1000000000
  ```
- output
  ```
  10000000
  ```

- Note

In the first sample case, Allen can withdraw this with a 100
 dollar bill, a 20
 dollar bill, and a 5
 dollar bill. There is no way for Allen to receive 125
 dollars in one or two bills.

In the second sample case, Allen can withdraw two 20
 dollar bills and three 1
 dollar bills.

In the third sample case, Allen can withdraw 100000000
 (ten million!) 100
 dollar bills.

```C
#include <stdio.h>

int main(){
    int n;
    int count = 0;
    scanf("%d", &n);
    while (n) {
        if (n>=100){
            count += n/100;
            n = n%100;
        } else if (n>=20){
            count += n/20;
            n = n%20;
        } else if (n>=10){
            count += n/10;
            n = n%10;
        } else if (n>=5){
            count += n/5;
            n = n%5;
        } else if (n>=1){
            count += n;
            n = 0;
        }
    }
    printf("%d\n", count);
    return 0;
}


```
