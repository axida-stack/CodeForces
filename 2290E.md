# E. Avalanche

time limit per test: 2 seconds

memory limit per test: 256 megabytes

There are 𝑛
 piles of stones in a row, numbered from 1
 to 𝑛
 from left to right. The 𝑖
-th pile contains 𝑎𝑖
 stones. You are also given an integer 𝑘

Alice and Bob play a game. They take turns, and Alice moves first. In one move, a player chooses a non-empty pile 𝑖
 and removes one stone from it. Then one new stone is added to each pile 𝑗
 such that max(1,𝑖−𝑘)≤𝑗≤𝑖−1

 and 𝑘=2
, one stone is added to each of piles 3

The player who cannot make a move loses. It can be shown that the game always ends after a finite number of moves.

Determine the winner if both players play optimally.

- Input

Each test contains multiple test cases. The first line contains the number of test cases 𝑡

The first line of each test case contains two integers 𝑛

It is guaranteed that the sum of 𝑛

- Output

For each test case, print Alice if Alice wins, and Bob otherwise.

#include <stdlib.h>
#include <iostream>
#include <vector>

using namespace std;
void solve(){
    int n, k;
    cin >> n >> k;
    vector<int> a(n), dp(n);
    for (int i=0; i<n; i++){
        cin >> a[i];
        a[i] %= 2;
    }
    int sum = 0;
    int ans = 0;
    for (int i=n-1; i>=0; i--){
        dp[i] = a[i]^sum;
        ans ^= dp[i];
        sum ^= dp[i];
        if (i+k < n){
            sum ^= dp[i+k];
        }
    }
    if (ans == 1)
        cout << "Alice\n";
    else
        cout << "Bob\n";
}
int main(){
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int t;
    cin >> t;
    while (t--) {
        solve();
    }
    return 0;
}
